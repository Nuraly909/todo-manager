# To-Do Manager

**Мақсат:** пайдаланушыға консольде күнделікті тапсырмаларын қосуға, көруге және басқаруға көмектесетін қарапайым қолданба.

## Команда
- Студент A: Product Owner + әзірлеуші
- Студент B: Scrum Master + әзірлеуші
(Ревьюер рөлі кезектесіп алмасады)

## Қалай іске қосу
python main.py

## Жұмыс ережелері
- Бұтақтар: `main` (тұрақты), `develop` (интеграция), `feature/<номер>-<қысқаша>`
- Коммит форматы: `feat: тапсырманы өшіру функциясын қосу (TASK-5)`
  Префикстер: feat, fix, docs, refactor, test
- main-ға тікелей коммит жасауға болмайды, тек pull request арқылы
- Әр PR-ды екінші адам тексеріп, кемінде 1 пікір қалдырады

## Функциялар
- `add_task(title)`: жаңа тапсырма қосу
